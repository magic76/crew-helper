# Crew Helper 使用者指南

## 位置方格：當 Crew 點不到你想點的位置

Shared Visual Reference 是**手動啟動**的輔助模式。Crew 不會因為搜尋錯誤、聽錯內容或一般按鈕找不到，就自動跳出方格。

### 怎麼開啟

直接對 Crew 說其中一句：

- `開方格`
- `我來選位置`
- `讓我指給你`
- `選位置`

英文也可以說 `Open grid`。

### 怎麼選

1. 畫面先出現 **1–12** 的大區域。
2. 說編號，例如 `12`，或說相對位置，例如 `右下角`。
3. Crew 會把該區再切成 **1–9**。
4. 再說一次編號或位置，例如 `5`。
5. Runtime 才會把最後確認的位置轉成座標並執行點擊。

### 範例：Google Maps 結束導航

```text
你：幫我結束導航
Crew：找不到這個控制項，需要的話可以說「開方格」自己指定位置。
你：開方格
→ 畫面顯示 1–12
你：右下角
→ 右下區域放大為 1–9
你：5
→ Runtime 執行點擊並驗證結果
```

### 重要行為

- `UI_TARGET_NOT_FOUND` **不會自動開方格**。
- 搜尋結果錯誤或語音辨識錯誤也不會自動開方格。
- 方格只在你明確要求時啟動。
- Gemini 不會取得或產生實際 x/y；座標只存在 Runtime。
- App 切換、螢幕尺寸改變、逾時或敏感畫面會取消方格。
- 敏感/高風險操作仍會被 Runtime 安全規則阻擋。

### 忘記怎麼用時

直接問 Crew：

- `方格怎麼用？`
- `我要怎麼自己指定點擊位置？`
- `你點不到時我怎麼幫你選位置？`

Crew 應只說明操作方式，不會因為你詢問說明就自動打開方格。
