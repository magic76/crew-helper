# Crew Helper 使用者指南

## 顯示元素：優先用真實可點擊 UI

當 Crew 找不到你要點的控制項，但畫面上的按鈕其實有 Accessibility 資訊時，可以直接說：

- `顯示元素`
- `顯示可點擊元素`
- `把可以點的標出來`

Crew 會在目前畫面的真實可點擊元素上畫框並標號。這不是固定方格；標記會依每個元素的實際 bounds 排列，近乎重複的 parent/child 會先去重，超大的容器不會搶走整個畫面。

接著只要說元素編號，例如：

```text
你：顯示元素
→ 畫面上的可點擊控制項出現 1、2、3、4…
你：4
→ Runtime 以 elementId 執行 tap_element 並驗證結果
```

元素模式不使用 x/y 座標。若你想點的東西根本沒有 Accessibility node，再改用「顯示方格」。

## 顯示方格：當元素模式也看不到目標

Shared Visual Reference 是**手動啟動**的位置 fallback。Crew 不會因為搜尋錯誤、聽錯內容或一般按鈕找不到，就自動跳出方格。

### 怎麼開啟

直接對 Crew 說其中一句：

- `顯示方格`
- `開方格`
- `我來選位置`
- `讓我指給你`
- `選位置`

英文也可以說 `Show grid` 或 `Open grid`。

### 怎麼選

1. 畫面先出現 **1–12** 的大區域。
2. 說編號，例如 `12`，或說相對位置，例如 `右下角`。
3. Crew 會把該區再切成 **1–9**。
4. 再說一次編號或位置，例如 `5`。
5. Runtime 才會把最後確認的位置轉成座標並執行點擊。

### 元素與方格可以直接切換

這兩種模式互斥。你可以隨時說：

```text
顯示元素
```

把方格關掉並改成 Accessibility 元素標記；或說：

```text
顯示方格
```

把元素標記關掉並改成位置方格。

### 範例：Google Maps 結束導航

```text
你：幫我結束導航
Crew：找不到這個控制項。
你：顯示元素
→ 如果 X 有 Accessibility node，畫面會直接標出元素編號
你：5
→ Runtime 點擊 element 5

如果 X 沒有被標出：
你：顯示方格
→ 畫面顯示 1–12
你：右下角
→ 右下區域放大為 1–9
你：5
→ Runtime 執行位置點擊並驗證結果
```

### 重要行為

- `UI_TARGET_NOT_FOUND` **不會自動開元素模式或方格**。
- 搜尋結果錯誤或語音辨識錯誤也不會自動開啟任何 visual assist。
- 兩種模式都只在你明確要求時啟動。
- `顯示元素` 優先使用 Accessibility elementId，不使用座標。
- `顯示方格` 才是 geometry/coordinate fallback。
- App 切換、螢幕尺寸改變、逾時或敏感畫面會取消目前 visual assist。
- 敏感/高風險操作仍會被 Runtime 安全規則阻擋。

### 忘記怎麼用時

直接問 Crew：

- `顯示元素怎麼用？`
- `方格怎麼用？`
- `我要怎麼自己指定點擊位置？`
- `你點不到時我怎麼幫你選位置？`

Crew 應只說明操作方式，不會因為你詢問說明就自動打開元素或方格。
